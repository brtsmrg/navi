# Navi: trademark brief for a Canadian agent

Not legal advice. This is a hand-over note so a Canadian trademark agent can clear and file the name quickly. Nothing here has been searched on the official register yet.

## The mark

- **Name:** Navi (a stylised logo also exists: white "Navi" with a red full stop, Barlow Condensed Bold Italic; files in `brand/logo/`).
- **Product name in stores:** Navi Rally.
- **Owner:** to be confirmed (individual or company). Licence in the repo: all rights reserved.
- **First use:** a public web app at https://brtsmrg.github.io/navi/ (no store release yet).

## What it covers

A rally co-driver app: plans a route, reads out pacenotes (corner direction and tightness) by voice and on-screen, and saves places and routes.

Suggested goods and services to discuss with the agent (Nice classification, current CIPO edition):

| Class | Why |
|---|---|
| 9 | Downloadable mobile application software for navigation, route planning and pacenote calling |
| 42 | Providing online non-downloadable software for route planning and pacenote generation |
| 41 | Optional: motorsport and driving-skills training content, if offered later |

Check with the agent whether to file one class first (government fee for the first class is roughly CAD 350 to file plus roughly CAD 130 on registration, plus about CAD 105 and 45 per extra class; confirm the current schedule on the CIPO fee page) and add others later.

## Risks to clear

- "Navi" is a short, common word and a common name for navigation features and products (car navigation, map apps, other software). Expect existing marks in classes 9 and 42. A full availability search of the CIPO Canadian Trademarks Database, plus common-law use, is the first job.
- Check close variants: NAVI, NAVEE, NAVY, NAVVY, NAVIGO and similar spellings, in English and French.
- Check domains and app-store names for the same word.
- If "Navi" alone is blocked, "Navi Rally" or the stylised logo may be filed as a fallback.
- Fonts: Barlow Condensed is under the SIL Open Font License 1.1, which allows use in a logo; see `docs/CREDITS.md`.

## Questions for the agent

1. Is "Navi" registrable for classes 9 and 42 given what is already on the register?
2. Standard characters, the logo design, or both?
3. File now on a proposed-use basis, or wait for the first store release?
4. Cost of a Madrid Protocol extension to the US and EU later.

## Where to search first (free)

- CIPO Canadian Trademarks Database (search by word, then by Nice class 9 and 42).
- US USPTO trademark search and EUIPO TMview, for the countries the app is likely to launch in.
